# ShipToPaid sales page

Source for [shiptopaid.com](https://shiptopaid.com). Next.js App Router, TypeScript, Tailwind CSS v4.

```sh
npm ci
cp .env.example .env.local   # optional
npm run dev
```

`NEXT_PUBLIC_POLAR_CHECKOUT_URL` sets the buy-button link (falls back to the live Polar checkout). `NEXT_PUBLIC_SITE_URL` is the canonical URL for Open Graph images. Deployed on Vercel.
